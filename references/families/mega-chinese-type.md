# Family: mega-chinese-type — 巨型中文透视标题视觉系

> 当 `family` 决议为 `mega-chinese-type` 时，先读这一份 family 规范，再去读所选具体 style（`references/styles/mega-chinese-type/<style>.md`）。

这个 family 的统一气质：**巨型中文透视标题 + 高冲突撞色 + 主题叙事插图 + 强空间纵深 + 电影级构图 + 潮流广告视觉 + 高传播感封面设计**。

**核心规则**：画面里的中文文字必须成为空间的一部分，像建筑、墙面、道路、赛道、巨大标牌、舞台、投影、地面结构、隧道结构或压迫性的视觉装置。文字不是说明文字，而是画面的空间结构本身。

## 设计师身份预设

声明角色：顶级电影海报设计师、潮流视觉导演、中文字体设计师、广告创意总监、运动品牌视觉设计师、电竞赛事主视觉设计师。

## 适用文章类型（路由依据）

| 文章 mood 关键词 | 推荐 style |
|---|---|
| 热血 / 速度 / 竞技 / 对抗 / 上线 / 突破 / 数字焦虑 | `esports-key-visual` |
| （后续可扩展：movie-poster / editorial-sports / fashion-campaign 等） | — |

如果文章语义偏冷峻、反叛、赛博、机甲控制室——**应路由到另一个 family `anime-pop`，不要硬塞 mega-chinese-type**。

## 整体视觉目标（family 通用）

画面必须接近：

- high-impact typography poster
- cinematic Chinese title design
- giant perspective typography
- bold color contrast
- editorial sports poster
- esports key visual
- movie poster composition
- dramatic advertising poster
- fashion campaign poster
- perspective text architecture
- visual storytelling poster

整体必须有强烈的第一眼冲击力：

- 第一眼看到巨大的中文标题
- 第二眼看到主题相关的人物、物体或场景
- 第三眼感受到文字与人物、物体、空间之间的关系

绝不能像：普通公众号封面、普通知识卡片、电商促销图、模板海报、平铺大字报、低级霓虹科技图、简单字加插画、无透视的普通标题排版。

## 中文标题必须极大（family 通用硬约束）

主标题必须是画面的绝对主角。

1. 中文标题必须巨大，占据画面主要面积
2. 标题不能只是普通横排或竖排
3. 标题必须具有强烈透视关系
4. 字体必须厚重、有力量、有空间感
5. 可以使用超粗黑体、立体字、压缩字、拉伸字、倾斜字、块面字、运动字、建筑字
6. 文字可以被拉长、压扁、错位、旋转、裁切、遮挡、延伸
7. 文字可以冲出画面边界，形成压迫感
8. 文字必须清晰可读，不能为了设计完全变形
9. 中文标题可以和英文、数字、小字系统形成层级
10. 标题必须像画面里的实体，而不是贴上去的文字

## 视觉面积分配（family 通用硬约束）

| 元素 | 全画面占比 |
|---|---|
| 中文标题文字（含 hero） | **50%–80% 视觉面积** |
| Hero 字宽度 | **≥ 55% 画面宽度** |
| 主题相关人物 / 物体 / 场景 | 15–30%，必须与文字发生结构关系 |
| 装饰小字 + 角色字段 | 5–10% |

英文 prompt 必须显式声明：

- `giant Chinese title text occupies 50% to 80% of the visual area, is the primary visual element`
- `hero text occupies at least 55% of frame width`
- `Chinese title has strong perspective, dramatic angle, deep spatial depth, and pressure`
- `figures or objects interact structurally with the title text, not floating independently`
- `do not produce a flat title-on-top-of-image layout; the title is architecture, road, wall, tunnel, projection, or stage`

## 三层文字系统（family 通用）

- **A 层 主视觉巨型透视字**：从原标题中提炼最有视觉张力的核心词作为巨大透视字。中文 2-8 字。承担整个画面的空间骨架。
- **B 层 完整主标题 / 副标题**：原标题完整呈现，副标题可有可无。
- **C 层 系统小字**：关键词 / 角色字段（handle/vol/no/date）/ 装饰文字 / 时间戳。

## 透视方式（family 通用，按主题自动选）

按主题自动选择最适合的中文标题透视方式。可用但不限于以下 10 种：

1. **地面透视字**——中文标题像铺在地面的巨大道路、赛道、城市地标或红毯，从前景向远处延伸。人物可站在字上、跑在字上、走向远方。
   适合：成长、路线、指南、冲刺、胜利、旅程、方法论。

2. **墙面透视字**——中文标题像巨大墙体、广告牌、城市建筑立面，从画面一侧向远处消失。人物可靠近墙面、从墙边跑出、被文字压迫。
   适合：商业、冲突、压迫、城市、社会议题、品牌主视觉。

3. **天花板压迫字**——中文标题从画面上方压下来，像巨大的天花板、招牌、结构梁或舞台装置。人物在下方显得渺小，形成戏剧感。
   适合：压力、危机、权力、命运、社会冲突。

4. **斜切冲击字**——中文标题以强烈斜角横穿画面，形成速度和攻击性。可配合人物奔跑、拳击、赛车、飞行、爆发动作。
   适合：热血、反叛、速度、运动、爆款观点。

5. **纵深隧道字**——文字一层层向远处重复或递进，形成隧道、走廊、通道、赛道感。人物位于中心或前景，像从文字世界中冲出来。
   适合：AI、科技、方法、系统、训练、游戏、未来感。

6. **巨型投影字**——标题像强光投射出的巨大阴影，落在地面、墙面或人物后方。文字可有长阴影和戏剧化光源。
   适合：电影感、悬疑、孤独、命运、人物故事。

7. **俯视透视字**——从高处俯视，文字像城市地面、地图、广场、楼顶标识。人物可成为小小的视觉锚点。
   适合：战略、地图、商业、城市、计划、系统。

8. **仰视巨物字**——从低角度仰视，文字像巨型建筑、纪念碑、雕塑或巨大标牌。人物在前景，文字产生英雄感和压迫感。
   适合：人物海报、冠军、胜利、品牌、宣言。

9. **环绕包围字**——中文标题围绕人物或物体形成包围结构，像舞台、漩涡、轨道或视觉陷阱。人物处于中心，被文字能量包围。
   适合：情绪、争议、流量、舆论、AI、社群、传播。

10. **断裂爆破字**——中文标题被撞开、撕裂、冲破、爆裂，但仍保持可读性。人物或物体可以从文字中冲出。
    适合：突破、反叛、改变、危机、重生。

**透视方式必须在 decisions JSON 里写出来**（字段名：`perspective_mode`），并在 prompt 里显式描述。

## 字体方向（family 通用）

- 超粗黑体（思源黑体 Heavy / 庞门正道 Heavy / 阿里巴巴普惠体 Bold）
- 立体字 / 压缩字 / 拉伸字 / 倾斜字 / 块面字 / 运动字 / 建筑字
- 中文 + 英文 + 数字三套小字系统形成层级
- **绝不允许圆润可爱字体、宋体、楷体、手写体作为 hero**

## 配色（family 默认倾向，可由 style 覆盖）

- 默认走"高冲突撞色"：红黑 / 紫绿 / 蓝粉 / 橙蓝 / 黄绿 / 青红 任选一组
- 配色必须形成强对比，禁止低饱和柔和组合
- 具体配色由所选 style 决定

## 严格禁止（family 通用）

- 标题排版平淡无透视
- 标题被插画压住或挤到画面边缘
- 多个小图标 / icon 墙 / 元素堆叠（pitch deck 感）
- 左右对称双区构图（左 metaphor / 右 title）
- 圆润可爱字体 / 楷体宋体作 hero
- 廉价科技蓝紫霓虹（除非 style 明确允许）
- 错别字 / 漏字 / 字体变形到不可读
- 普通商业插画感 / 电商促销图感 / 模板海报感
- 未授权品牌 logo（Canon / Honda / OpenAI / Anthropic / Adidas / Nike 等）
- 任何文字最终读不出标题原文

## 装饰文字溯源（family 通用）

跟 anime-pop family 一样的三类来源（A 文章导出 / B style 中性词模板 / C 与文章对应的编号-坐标-时间戳），每条 decoration_text 都要在 decisions JSON 里写 source。

## 角色字段（family 通用强制）

`handle` / `vol` / `no` / `date` 四项必须全部出现在画面中。**具体摆放位置见所选 style reference 文件**。

## family-level self-check

- [ ] 中文 hero 占画面 ≥ 50% 宽度，全部文字占画面 50%–80%
- [ ] hero 字具有强透视（地面 / 墙面 / 天花板 / 斜切 / 隧道 / 投影 / 俯视 / 仰视 / 环绕 / 断裂 十选一）
- [ ] hero 字与人物 / 物体 / 场景形成结构关系，不是飘在图上面的贴纸
- [ ] 配色形成强对比（撞色 / 高冲突），不是低饱和柔和组合
- [ ] hero 字体厚重、有力量、有空间感（无圆润可爱字体）
- [ ] 单一主图像锚点，不是 icon 墙 / 双区对称
- [ ] 标题清晰可读，没有为了设计完全变形
- [ ] 角色字段 4 项齐全
- [ ] 每条 decoration_text 都有 source
- [ ] hero 是画面里唯一的"巨型"字位

## English Prompt Opener 选择

opener 一定从所选 style reference 里推荐的"family 通用 + style 专属"短语中选，绝不写商业品牌名。family 通用兜底词组：

- ✅ `high-impact Chinese typography poster with giant perspective title`
- ✅ `cinematic Chinese title design with deep spatial depth and bold color contrast`
- ✅ `editorial poster aesthetic where the Chinese title is architecture, not overlay`
- ❌ `Nike-style sports poster`（品牌名）
- ❌ `League of Legends key visual style`（IP 名）
