# P5 Style — Bold Red-Black-White Manga Rebel Aesthetic

> 当 `style` 决议为 `p5` 时,在生成 decisions 与英文 image prompt 之前,必须读这一份。

## 主色

- 纯黑 `#000000`(背景)
- 反叛红 `#e60012`(主强调)
- 纯白 `#ffffff`(hero 字 / 关键元素)

**仅这三色,严禁混入第四色**。

## 关键视觉元素

漫画半色调网点 / 锐角撕裂边 / 不规则切角 / 印章式戳记 / 飞溅版式 / 倾斜 ±5° 动感线 / 跨页式拼贴

## 字体

- 中文 hero:粗黑体加倾斜或印章感(Source Han Sans Heavy + 旋转 ±7°)
- 英文 hero / B 层:粗体压缩 + 极强字间挤压
- 小字 / 装饰:粗压缩无衬线 / 等宽

## 气质

全员集结开场,暴烈、锐利、痛快。"觉醒""戳穿""反共识"的视觉。

## 图像锚点(可用)

戴面具(非原作样式)的剪影 / 锁链 / 卡牌 / 撕裂的城市 / 单一独行者剪影 / 倒影。
**卡牌、面具、剪影上不能写下方 IP 黑名单中的任何文字。剪影若戴面具,必须避开多米诺面具(domino mask)等原作样式。**

## 装饰文字原则

**严禁出现下列原作 IP 专有名词作为可读文字**:

- `Persona`
- `TAKE YOUR HEART`
- `SHOWTIME`
- `ALL-OUT ATTACK`
- `怪盗団`
- `心の怪盗`
- `ベルベットルーム`

**正确做法**:从文章关键词提炼短促有力的英文动词或感叹词(口令感)+ 文章核心中文短语作为印章。

- 中文文章关键词作大印章:基于文章自身的核心词(如本月写过的"反共识"、"命题"、"决策"、"从零")
- 中性英文口令短词:`READY` / `GO` / `BREAK` / `HEAT` / `STRIKE` / `CONFRONT`
- 编号 / 章节计数:`01—13`、`No.005`、`CH.07`

## 边框倾向

不规则撕裂边或对角切角,也可无框。
若全画面已有强对角刀痕作为结构线,则不再加任何矩形边框。

## 角色字段摆放惯例

印章戳记式分散三角:

- 顶部右上:`<vol>` 撕边小白标 + 红字,旋转 -4°
- 顶部左上:`<date>` 黑底白字小印章
- 底部右下:`@<handle>` 黑字白底印章,旋转 +3°

## 英文 prompt 推荐 opener 用语(回避 IP 词)

- ✅ `bold red-black-white manga rebel poster aesthetic`
- ✅ `late-2010s Japanese stylized comic graphic design`
- ❌ `Persona 5 all-out attack splash`
- ❌ `phantom thief poster style`
